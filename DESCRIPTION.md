# Description

## English

Software Feasibility Scout is an agent skill for discovering and validating software opportunities before development. It combines real user pain from public communities, Google search trends, TikTok content trends, competitor and alternative research, and payment signals to identify problems that can become focused, directly monetizable websites, mobile apps, or AI products. The skill separates evidence from assumptions, checks whether a problem is still current, records counter-evidence, and produces a practical recommendation: build, run a fast experiment, keep watching, or archive.

## 中文

Software Feasibility Scout 是一个在开发前发现和验证软件机会的 Agent Skill。它结合公开社区中的真实用户痛点、Google 搜索趋势、TikTok 内容热点、竞品与替代方案调研以及付费信号，寻找适合开发成网站、手机 App 或 AI 产品的具体问题。它会区分事实证据和研究假设，检查需求是否仍然存在，主动寻找反证，并给出可执行结论：优先开发、快速实验、继续观察或归档。
